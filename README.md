## 项目简介

复合机器人系统：差速移动底盘 + 四轴机械臂，基于 ROS 2 Jazzy 与瑞莎 A733 边缘计算平台，
完成「自主巡检 — 违停识别 — 车牌取证 — 自动贴单 — 返航停靠」全流程。
